# CodeAlpha Task 2 — Stock Portfolio Tracker

A simple console-based Python application that calculates total investment value using manually defined stock prices and user-entered quantities.

## Objective

Practice dictionaries, input/output, arithmetic, loops, validation, and basic file handling.

## Features

- Predefined stock prices
- User enters stock symbol and quantity
- Validation for unknown stocks and invalid quantities
- Multiple stock entries
- Per-stock and total investment calculation
- Optional save to portfolio.txt

## Concepts Used

- Python dictionaries
- User input and output
- Basic arithmetic
- Loops
- Functions
- File handling
- Input validation

## Project Structure

CodeAlpha_StockPortfolioTracker/
├── README.md
└── main.py

## How to Run

Run: python main.py

No third-party packages are required.

## Example

AAPL: 10 shares x $180.00 = $1800.00
TSLA: 5 shares x $250.00 = $1250.00
Total Investment: $3050.00

Note: The stock prices are fixed examples for this internship project, not real-time market prices.
